The Backtest That Lied

Asit Minz

An automated BTC-futures bot running unattended on a low-cost ARM box, validated for months against a backtest reporting +90.7% a year. The real figure is +13.7%. Two bugs had been cancelling each other out inside the one invariant anyone thought to check — and the lesson (an invariant that holds is not proof) applies directly to how you test any non-deterministic system, evals included.

The SDK That Vanished

Asit Minz

Crypto-DEX ran with no backend by delegating every read to a hosted Web3 API and every swap route to a server-side plugin. Then the vendor discontinued that product, and it failed silently — a guard clause returning null, no error anywhere. The reframe — “does this need an indexer?” rather than “is it a read or a write?” — turned 19 files into 3. Six critical advisories in the production bundle finished the last 3, in the wrong order and a week early.

Asit Minz
